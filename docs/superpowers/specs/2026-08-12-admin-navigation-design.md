# SeventEnglish 导航栏重构设计

- 日期：2026-08-12
- 状态：已完成设计，待用户审阅
- 范围：全局导航栏与管理工作台导航的视觉和层级重构

## 一、目标

解决当前顶部全局导航与管理页面左侧导航不协调的问题：

- 顶部同时出现“阅读 / 听力 / 设置 / 管理”。
- 管理页面内部又出现“文章 / 听写 / AI模型”侧栏。
- 品牌 Logo 在顶部和管理侧栏重复出现。
- 移动端顶部链接空间不足，容易换行和错位。

重构后将导航明确分为两种模式：

```text
学习模式：顶部学习导航
管理模式：顶部管理上下文 + 左侧管理导航
```

不改变现有业务路由和页面功能，只调整导航结构、状态识别、视觉层级和响应式表现。

## 二、产品决策

### 2.1 管理模式

当路径以 `/admin` 开头时，进入管理模式：

```text
┌──────────────────────────────────────────────────────────────┐
│  SeventEnglish · 管理工作台                  ← 返回学习端     │
├───────────────┬──────────────────────────────────────────────┤
│  文章          │                                              │
│  听写          │              管理页面内容                    │
│  AI模型       │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

顶部导航只显示：

- 完整 `SeventEnglish` 品牌。
- 上下文标签“管理工作台”。
- “返回学习端”入口。

管理模式隐藏顶部的“阅读 / 听力 / 设置 / 管理”链接，避免重复层级。

### 2.2 品牌层级

采用“顶部统一品牌”：

- 顶部保留完整 `SeventEnglish` 品牌。
- 管理侧栏移除重复的大 Logo。
- 管理侧栏顶部使用紧凑的“管理模块”提示或直接从导航项开始。
- 品牌只承担全局身份，侧栏只承担模块切换。

### 2.3 学习模式

`/read`、`/listen`、`/settings` 等非管理页面保持学习模式：

```text
SeventEnglish       阅读   听力   设置   管理
```

学习端不显示管理侧栏，不改变现有页面导航语义。

## 三、组件设计

### 3.1 `src/components/Nav.tsx`

使用 `useLocation` 判断当前路由：

```ts
const isAdminMode = location.pathname.startsWith("/admin");
```

根据模式渲染不同导航结构：

- 学习模式：现有学习端顶部导航。
- 管理模式：品牌、`管理工作台`上下文标签和返回学习端链接。

建议的结构类名：

```text
nav nav--learning
nav nav--admin
nav-brand
nav-admin-context
nav-admin-return
```

`Nav` 不负责管理模块侧栏，侧栏继续由 `AdminLayout` 内部渲染。

### 3.2 `src/components/admin/AdminSidebar.tsx`

移除侧栏内的重复 Logo 和完整 `WORKSPACE` 品牌区，只保留：

- 文章
- 听写
- AI模型

当前路由继续由 `NavLink` 通过 `aria-current="page"` 表达。侧栏使用语义化 `<nav aria-label="管理模块导航">`。

### 3.3 `src/pages/admin/AdminLayout.tsx`

保留现有布局职责：

- 渲染 `AdminSidebar`。
- 渲染主内容 `<Outlet />`。
- 不再额外承担 Logo 或顶部导航职责。

管理工作台高度应基于全局导航栏实际高度计算，避免顶部导航变体导致内容被遮挡。

## 四、视觉与交互规则

### 4.1 顶部导航

管理模式顶部导航与管理工作台使用同一套暖米色、深红、深褐色视觉语言：

- 品牌文字和管理上下文在视觉上成组。
- `管理工作台`使用低调的上下文徽标，而不是一级导航按钮。
- “返回学习端”使用幽灵按钮或低对比度链接，不与主操作按钮竞争。
- 保留清晰的键盘焦点和 hover 状态。

学习模式保持原有轻量顶部导航，但统一 spacing、active 状态和移动端处理。

### 4.2 管理侧栏

- 侧栏背景与管理工作台深色 Shell 保持一致。
- active 模块使用深红色背景和白色文字。
- 非 active 模块使用低对比度米灰文字。
- 侧栏只包含模块导航，不放全局品牌和学习端入口。
- 学习端返回入口只出现在顶部，避免侧栏底部重复。

### 4.3 移动端

桌面端：

```text
顶部导航 + 232px 管理侧栏 + 主内容区
```

窄屏端：

- 顶部品牌保留，但字号缩小。
- `管理工作台`变为紧凑徽标。
- “返回学习端”保留图标和短文本。
- 管理侧栏收缩为图标栏。
- 图标仍保留 `aria-label` 和可访问名称。
- 顶部学习模式链接不再依赖自然换行，避免导航高度错乱。
- 管理页面抽屉继续使用全屏布局。

## 五、路由与兼容性

导航重构不改变以下路由：

```text
/read
/listen
/settings
/admin/articles
/admin/dictation
/admin/ai-model
```

旧 `/admin/books` 重定向仍由现有路由处理。

路由模式只影响导航渲染，不修改文章、听写、AI 模型业务逻辑和 API。

## 六、可访问性

- 顶部和侧栏使用语义化 `<nav>`。
- 当前页面通过 React Router `NavLink` 提供 `aria-current="page"`。
- 返回学习端链接有明确文本，不只依赖箭头图标。
- 侧栏图标不承担唯一语义，窄屏模式保留 `aria-label`。
- 导航项支持键盘 Tab 和清晰 focus ring。
- 颜色不是表达 active、hover 或错误状态的唯一方式。

## 七、测试与验证

新增/更新导航测试：

- `/read` 渲染学习模式导航。
- `/listen` 渲染学习模式导航。
- `/settings` 渲染学习模式导航。
- `/admin/articles` 渲染管理模式导航。
- `/admin/dictation` 和 `/admin/ai-model` 同样渲染管理模式。
- 管理模式不显示顶部学习端链接。
- 管理模式显示“管理工作台”和“返回学习端”。
- 管理侧栏显示文章、听写、AI模型三项。
- 当前管理模块具有 active 状态。
- 返回学习端链接指向 `/read`。

浏览器验证：

- 桌面宽度检查顶部、侧栏和内容区的衔接。
- 移动宽度检查顶部导航不换行错位。
- 检查 `/admin/articles`、`/admin/dictation`、`/admin/ai-model` 的一致性。
- 检查浏览器控制台无错误。

最终运行：

```bash
npm test
npx tsc --noEmit
npm run build
```

## 八、非目标

本轮不做：

- 用户侧阅读页面视觉重构。
- 用户侧听力练习页面视觉重构。
- 管理侧栏新增业务模块。
- 改变路由、权限和认证逻辑。
- 引入新的 UI 框架或图标依赖。
- 修改文章、听写和 AI 模型 API。
